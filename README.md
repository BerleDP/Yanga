# App description
C'est une application d'E-commerce conçu pour des services de vente et d'achat.

# User story
- Permet de voir les produits locaux
- L'utilisateur peut voir les produits artisanaux
- L'utilisateur peut promoter des produits locaux
- On peut acheter et vendre des produits.
